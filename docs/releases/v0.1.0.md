# GitHub Link v0.1.0

首个 macOS arm64 版本。

## 功能

- GitHub 专用本地 HTTP CONNECT 代理与 PAC 服务。
- 系统 DNS、腾讯 DoH、阿里 DoH、Cloudflare DoH 并行解析。
- 候选 IP TCP/TLS 验证、双 IP 竞速及 TLS ClientHello 超时重放。
- Git HTTPS 与 SSH 用户级配置接入，支持 SSH 443 回退。
- HTTP CONNECT / SOCKS5 上游代理及自动回退。
- launchd 后台 daemon、Unix Socket 控制协议和诊断 CLI。
- Tauri 菜单栏界面，展示连接评分、线路、IP 与 TCP/TLS 延迟。

## 安全

- 不安装自签 CA。
- 不解密 HTTPS。
- 不修改 Git `http.sslverify`。
- 不读取 GitHub Token 或 SSH 私钥。
- 仅监听回环地址，只允许 GitHub 白名单域名及 `443/22` 端口。
