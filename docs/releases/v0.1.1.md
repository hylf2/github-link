# GitHub Link v0.1.1

`v0.1.1` 修复 App 在重新打开或用户重新登录后，后台 daemon 尚未就绪时显示 `Daemon unavailable: Connection refused (os error 61)` 的问题。

## 修复内容

- App 连接控制 Socket 失败时，自动执行 `launchctl kickstart`。
- LaunchAgent 未注册或 kickstart 后仍不可用时，自动重新安装并启动 daemon。
- daemon 启动后最多重试 4 秒，避免启动竞态被直接显示为永久错误。
- `github-link enable` 最多等待 6 秒，确认控制 Socket 可用后才返回成功。
- 空控制响应现在会显示明确错误，不再进入模糊的 JSON 解析失败。

## 验证场景

验收时主动卸载 `com.fengc.github-linkd` LaunchAgent，并保留失效的 `control.sock`，随后打开 App。App 成功重新注册 daemon，恢复以下服务：

| 服务 | 地址 |
|---|---|
| CONNECT 代理 | `127.0.0.1:38457` |
| PAC 服务 | `127.0.0.1:38458` |
| 控制 Socket | `~/Library/Application Support/GitHubLink/control.sock` |
