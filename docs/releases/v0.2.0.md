# GitHub Link v0.2.0

`v0.2.0` 新增 GitHub 下载镜像加速，结合 `github.akams.cn` 聚合节点与本地实测结果，为公开下载链接选择当前响应最快的节点。

## 新增功能

- 从 `github.akams.cn` 自动发现候选镜像节点，失败时使用内置候选。
- 对候选节点执行延迟探测，并缓存 10 分钟结果。
- 用户粘贴 Release、Archive、Raw、Gist 或 Codeload 链接后，使用实际目标做带 Range 的二次测速。
- 自动生成最佳镜像 URL，可复制或直接在系统浏览器中打开。
- App 设置页提供独立开关和节点发现页面配置。
- CLI 新增 `github-link mirrors` 与 `github-link accelerate`。

## 安全边界

- 下载加速默认关闭。
- 只接受公开 GitHub 下载 URL，拒绝 API、认证信息和普通网页地址。
- 第三方镜像不接收 GitHub Token。
- 不修改 Git 的 TLS 验证，不安装 CA，不进行 HTTPS 中间人解密。
- 镜像节点来自第三方公益服务，下载产物应结合发布者提供的 SHA-256 或签名核验。
